## Descrição do sistema

Sistema para acompanhar e gerir a cadeia de suprimentos: fornecedores, lotes, entradas e saídas de material, do campo até o cliente final. Permite saber quem fornece, o que fornece e para onde cada lote vai, rastreando a origem do material e dando base para relatórios e controles de conformidade.
